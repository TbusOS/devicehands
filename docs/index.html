DeviceHands 让云端的大模型、你身边的本地模型、设备里的小模型一起调试真实硬件:亲自进到设备里去查,互相商量,再把结论画给你看。 DeviceHands lets a large cloud model, a local model near you and a small model on the device debug real hardware together: they go inside the device, talk it over, and draw you the answer.

TP02 · 脑MINDS

一个 bug,
几个模型一起看One bug.
Several models on it.

云端大模型负责推理,本地小模型守着整条日志流。它们交换证据、互相质疑,最后交给你一份看得懂的报告。这是它和传统调试工具最不一样的地方。A cloud model does the reasoning while a small local model reads the whole log stream. They trade evidence, challenge each other, and hand you a report you can read. This is where it parts ways with traditional debug tools.
